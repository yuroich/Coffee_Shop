# Brewed & Blessed Coffee Shop ☕

A clean, modern, and fully responsive website for **Brewed & Blessed** — a small coffee shop that serves handcrafted drinks made with locally sourced beans.

This site was built as a single-file HTML website, making it easy to host anywhere with zero setup required.

## What's on the site

- **Menu** — Hot coffee, cold coffee, non-coffee drinks, and pastries with prices in ₱
- **Our Story** — A short introduction to the shop and its values
- **Order & Contact** — A form for customers to place pickup orders or send inquiries
- **Shop details** — Address, operating hours, and contact information

## Tech used

- Plain HTML, CSS, and JavaScript — no frameworks, no dependencies
- Google Fonts (Playfair Display + Lato)
- Fully responsive — works on mobile phones, tablets, and desktops
- No backend required

## How to run locally

Just open `index.html` in any web browser. That's it.
